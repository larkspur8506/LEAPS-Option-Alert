# QQQ LEAPS 信号回测（独立复核）

2026-10-11 用纯 stdlib 引擎重做的独立回测。**它复现不出**早期 README 里的
「49 笔 / 期望 +63~74% / 2010+ CAGR 103%」——那批数字来自已丢失的旧脚本，
对应的是「tp80 或不设止盈」家族。**以本目录口径为准**。

## 怎么跑

```bash
cd backtest
python3 fetch_data.py            # 首次/更新数据 (FRED 公开序列, 免 key)
python3 leaps_sweep1.py          # 入场过滤 / RSI 阈值 / 样本分段
python3 leaps_sweep2.py          # 加仓档位 / 分批止盈 / Δ 与期限 / 长样本稳健性
python3 leaps_sweep3.py          # 分层止盈 (RSI 卖半 + 余仓放宽) + 池级口径
python3 leaps_sizing.py          # 不同下单规模下的年化与尾部
```

无第三方依赖（无 numpy/pandas）；数据是 FRED 的 CSV，随仓库附带，
`fetch_data.py --check` 可看本地是否落后于远端。

## 数据与定价口径

| 项 | 取值 | 来源 |
|---|---|---|
| 标的 | 纳斯达克100 指数（QQQ 代理） | FRED `NASDAQ100`（1986→） |
| 隐含波动率 | VXN 收盘 | FRED `VXNCLS`（2001-02→；更早用 20 日实现波动率年化兜底） |
| 无风险利率 | 3 个月国库券 | FRED `DGS3MO` |
| 定价 | Black-Scholes，含分红率 q=0.55% | 逐日重估 |
| 行权价 | 按目标 delta 反解、取整 $5 | — |
| 成本 | 每边按权利金 `spread_pct`（默认 0） | 买价 = mid×(1+s/2)，卖价 = mid×(1−s/2) |

用指数代理 QQQ 是等价的：信号口径相同，期权收益对 S/K 同比缩放不变，
所以绝对价位不影响百分比收益。**真实期权报价拿不到**（Yahoo 从所有出口 IP 都 429），
30 天 VXN 也系统性高于 1 年期 IV，故**绝对收益大概率偏高**，但参数之间的排序稳定。

## 规则（与 `app/alerts/qqq_rules.py` 对齐）

- 入场：`RSI14 < 35` 且 `收盘 > 252 交易日前收盘`（收盘确认制）
  - 「连续 3 日 > SMA200」已于 2026-10-11 移除
- 退出（先到先出）：`RSI14 > 65` 全平止盈 → DTE ≤ 90 强平；时间止损/价格止损默认关闭
- 加仓：相对 `signal_base_price` 回撤 -15% / -25% 且 RSI 仍 < 35
- 分批止盈：默认关闭（+50% 阈值在 tp65 下从不触发）

## 关键结论（2001-02 → 2026-10，无成本）

线上参数（Δ0.65/365d/tp65/dte90）：**28 笔、胜率 85.7%、均值 +13.2%、中位 +13.5%、
最差 -39.2%、复利 CAGR 12.6%、平均持仓 50 天、约 1.1 笔/年**。

| 改动 | 结论 |
|---|---|
| 去掉「连续 3 日 > SMA200」 | CAGR 12.6% → **15.1%**，最差单笔不变（-39.2%）→ 已采纳 |
| 去掉「收盘 > 一年前」 | 最差单笔 **-95.8%**、权益 0.02x（爆仓）→ **必须保留** |
| Δ 0.65 → **0.70** | 均值 +16.7%、最差 **-31.9%**（1987-2026 长样本同向：CAGR 10.3% → 13.9%）→ 已采纳 |
| Δ → 0.75 | 均值 +19.5%、最差 -23.3%（更激进，尾部收益同时改善但成本更高） |
| 价格止损 / 时间止损 | **全部降低 CAGR、恶化尾部** → 不加 |
| 加仓 -15%/-25% | 关掉则最差 -65.7%、CAGR 6.6% → 保留（第三档 26 年从未触发） |
| 分批止盈（按盈利） | tp65 下**从不触发**（均值 +13% < +50%）→ 已关闭 |
| 分批止盈（改 RSI 口径） | 卖半@65 + 余仓@80：均值 +43.6%、满仓 +25%/年，但**最差单笔恶化到 -72.5%** |
| 成本 1.5%/边 | 每笔约 -1pp；3%/边 → CAGR 12.6% → 9.0% |

### 规模决定收益（$100k 固定本金、利润不滚动）

| 下单规模 | 年化 |
|---|---|
| 固定 1 张 | +0.49% |
| 固定 3 张 | +1.47% |
| 满仓（≈额度 ÷ 单张成本，当前约 9-13 张） | **+14.05%**（Δ0.70 → ≈ +18%） |

**池级收益几乎完全由下单规模决定，而不是由信号微调决定。**
app 侧据此新增「额度上限」机制：默认 `总资产 × 12.5%`（$800k → $100k），
信号提醒里给出建议张数与额度占用（仅为建议，以实际录入仓位为准）。

## 局限

- 样本仅 28 笔（2001-2013 九笔 / 2014-2026 十九笔），两段 CAGR 8.2% vs 17.2%，
  后段是牛市窗口 → 点估计脆弱，**只接受跨样本方向一致的改动**，不做精细调参。
- 指数代理 + BS 定价（无真实期权链、无提前行权、无分红调整路径）。
- 未建模：行权价档位流动性、单张合约的最小跳动、滑点随规模变化。
